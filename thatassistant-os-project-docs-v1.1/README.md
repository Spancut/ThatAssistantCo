# ThatAssistant OS — Claude Code Project Documentation

This folder contains the source-of-truth documentation for building **ThatAssistant OS — VA Edition**.

ThatAssistant OS is a Human + AI client-delivery operating system for professional VAs and EAs. It helps them manage communication, calendars, meetings, projects, client lifecycle work, systems, executive support and follow-up across multiple clients.

## Start here

1. Read `CLAUDE.md`.
2. Read `docs/00-source-of-truth-index.md`.
3. Read `docs/10-blueprint-revision-1.1.md`.
4. Read the relevant supporting document for the feature being planned.
5. Do not write production code until the current Part 11 build phase has been approved.
