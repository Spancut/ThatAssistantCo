# Product Experience and UX Specification

## Experience principles

- outcome-first, not agent-first
- active client always visible
- one clear next action
- progressive setup
- complete approval bundles
- exceptions over surveillance
- evidence before confidence
- ambiguity visually distinct from failure
- calm density
- easy correction
- accessible language
- mobile prioritises oversight and decisions

## Home — What Needs You

Home should show:

- urgent issues
- approvals
- missing information
- unclear owners or dates
- sensitive communication
- blocked or overdue work
- follow-ups due
- onboarding or renewal risk
- upcoming executive decisions
- travel or event decisions
- weekly updates ready
- weekly review prompt

## Activation

The first-value experience should take approximately 10–15 minutes:

1. Create one client.
2. Add only the minimum context required.
3. Submit one real or sample request.
4. Review the proposed plan.
5. Approve or correct it.
6. See the work and waiting states created.

## Core exception states

- missing client context
- uncertain client identity
- conflicting sources
- unclear owner
- unclear deadline
- stale approval
- possible duplicate action
- failed external action
- disconnected integration
- partial completion
- safe mode
