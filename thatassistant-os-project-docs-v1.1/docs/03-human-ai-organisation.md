# Human + AI Organisation

## Human authority

### VA — Head of Client Delivery

The VA owns:

- client relationships
- service scope
- priorities
- sensitive communication
- commercial judgement
- final approval
- privacy
- exceptions
- decisions that affect trust

## Coordinator

### Client Operations Director

Coordinates work across all product pillars. It:

- confirms the operational objective
- checks workflow eligibility
- creates bounded work orders
- sequences specialist roles
- preserves unresolved ambiguity
- combines validated results
- recommends the next workflow stage

It cannot increase autonomy or bypass deterministic controls.

## Specialist roles

### Client Context Steward

- Client Brain records
- source authority
- contacts and preferences
- stale or conflicting information
- service scope
- proposed context updates
- private-context separation

### Client Communications Agent

- acknowledgements
- replies
- clarification requests
- follow-ups
- progress and completion updates
- sensitive communication flags

### Calendar and Meetings Agent

- scheduling rules
- availability requirements
- buffers and time zones
- attendee coordination
- scheduling proposals
- meeting briefs
- meeting analysis and action plans

### Projects and Delivery Agent

- task and project classification
- owners and deadlines
- milestones and dependencies
- blockers and project risk
- completion criteria
- delivery reporting

### Client Lifecycle Agent

- onboarding
- readiness
- records and service activation
- reviews and renewals
- offboarding and archiving

### Follow-Up and Coordination Agent

- waiting states
- reminder preparation
- completion checks
- attempt limits
- partial responses
- escalation

### Systems and SOP Agent

- process intake
- SOP generation
- step and owner analysis
- checklists and exceptions
- versions
- approved publication

### Executive and Personal Assistance Agent

- executive briefs
- personal administration
- important dates
- private preferences
- travel and event planning
- confidential escalation

### Quality, Risk and Permissions Agent

AI-supported review of:

- source support
- consistency
- client rules
- privacy
- sensitivity
- recipient risk
- scope risk
- unsupported claims

Actual permission enforcement remains deterministic.

## Agent execution rules

- one bounded objective per work order
- minimum necessary context
- typed structured results
- source references for material claims
- explicit uncertainty
- no external execution
- no self-approval
- no silent Client Brain learning
