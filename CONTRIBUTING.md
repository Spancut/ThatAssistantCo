# Contributing

1. Read `AGENTS.md`, the governing roadmap, and the assigned numbered ticket.
2. Work only on that ticket and preserve unrelated changes.
3. Use fictional fixtures and never commit secrets, provider payloads, or real client data.
4. Run the checks applicable to the ticket.
5. Update the build journal and stop for review before beginning another ticket.

Product, architecture, security, tenancy, AI, workflow, and release requirements come from the source hierarchy in `docs/source-of-truth-index.md`. Do not invent missing requirements.
